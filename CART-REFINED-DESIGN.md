# 🛒 Trang Giỏ Hàng Gomie - Thiết Kế Tinh Gọn & Tối Ưu

## ✨ Nguyên Tắc Thiết Kế

### 🎯 **Focus & Hierarchy**

- **Tập trung vào action chính**: Checkout button nổi bật nhất
- **Hierarchy rõ ràng**: Thông tin quan trọng được ưu tiên hiển thị
- **Loại bỏ noise**: Giảm thiểu các element không cần thiết

### 📐 **Layout & Spacing**

- **Consistent spacing**: Sử dụng hệ thống spacing đồng đều
- **Balanced proportions**: Grid 1fr + 380px cho desktop
- **Compact design**: Tối ưu không gian hiển thị

### 🎨 **Visual Design**

- **Clean aesthetics**: Giao diện sạch sẽ, hiện đại
- **Gomie colors**: Primary blue (#0b89e7) + Secondary orange (#ef661a)
- **Subtle effects**: Chỉ giữ lại animations cần thiết

## 🔧 **Cải Tiến Chính**

### **1. Header Section - Simplified**

```css
- Compact title (1.75rem) với icon nhỏ gọn
- Simple breadcrumb navigation
- Minimal spacing và clean borders
- No complex gradients or animations
```

### **2. Cart Items - Streamlined**

```css
- Clean card design với subtle shadows
- Compact item layout (80px images)
- Smart text truncation (2-line clamp)
- Efficient quantity controls
- Streamlined actions layout
```

### **3. Summary Section - Focused**

```css
- Fixed width (380px) cho consistency
- Clear pricing hierarchy
- Compact coupon form
- Prominent checkout button
- Sticky positioning on desktop
```

### **4. Responsive Design - Mobile First**

```css
- Single column layout trên mobile
- Touch-friendly controls
- Optimized spacing cho mobile
- Static positioning trên mobile
```

## 📱 **Responsive Breakpoints**

### **Desktop (>992px)**

- 2-column grid layout
- Sticky sidebar
- Hover effects
- Optimal spacing

### **Tablet (768px - 992px)**

- Single column layout
- Static sidebar
- Adjusted spacing
- Touch-optimized controls

### **Mobile (<768px)**

- Vertical layout
- Full-width elements
- Compact spacing
- Mobile-first interactions

## 🎨 **Color System**

### **Primary Actions**

- **Checkout Button**: Orange (#ef661a) - Most prominent
- **Update Cart**: Blue (#0b89e7) - Secondary action
- **Continue Shopping**: Outlined blue - Tertiary action

### **Content Hierarchy**

- **Headers**: Blue (#0b89e7) - Brand color
- **Prices**: Orange (#ef661a) - Attention grabbing
- **Text**: Neutral grays - Easy reading
- **Borders**: Light grays - Subtle separation

## 📏 **Typography Scale**

### **Headers**

- Page Title: 1.75rem (desktop) → 1.25rem (mobile)
- Section Headers: 1.1rem
- Item Names: 1rem với line-clamp

### **Body Text**

- Primary Text: 0.9rem
- Secondary Text: 0.8rem
- Buttons: 0.9rem - 1.1rem

### **Spacing System**

- Container: 2rem padding
- Section gaps: 1.5rem - 2rem
- Item spacing: 1rem - 1.25rem
- Element gaps: 0.5rem - 1rem

## 🔄 **Interaction Design**

### **Hover States**

- Subtle background changes

- No complex animations

### **Focus States**

- Clear focus rings
- Accessible color contrast

### **Loading States**

- Minimal visual feedback
