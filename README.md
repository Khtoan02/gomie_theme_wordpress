# Gomie Vietnam WordPress Theme

## Giới thiệu

Gomie Vietnam Theme là một WordPress theme chuyên nghiệp được thiết kế dành riêng cho thương hiệu gốm sứ thủ công Gomie Việt Nam. Theme này kết hợp giữa phong cách Liquid Glass hiện đại với tâm hồn nghệ thuật thủ công truyền thống.

## Tính năng chính

### 🎨 Thiết kế

- **Liquid Glass Design**: Phong cách thiết kế hiện đại với hiệu ứng kính lỏng
- **Responsive Design**: Tương thích hoàn hảo trên mọi thiết bị
- **Warm Color Palette**: Bảng màu ấm áp với tông cam, be và nâu
- **Typography**: Font chữ hiện đại và dễ đọc

### 🏺 Nội dung Gomie

- **HEART Values**: 5 giá trị cốt lõi (H-E-A-R-T)
- **Product Showcase**: Trưng bày sản phẩm gốm sứ thủ công
- **Craftsmanship Story**: Câu chuyện về nghệ thuật thủ công
- **Community Connection**: Kết nối cộng đồng yêu nghệ thuật

### 🛠️ Tính năng kỹ thuật

- **WordPress 5.0+ Compatible**: Tương thích với WordPress phiên bản mới nhất
- **SEO Optimized**: Tối ưu hóa cho công cụ tìm kiếm
- **Fast Loading**: Tải trang nhanh với tối ưu hóa hiệu suất
- **Customizer Ready**: Tùy chỉnh dễ dàng qua WordPress Customizer

## Cài đặt

1. **Upload Theme**: Tải theme lên thư mục `/wp-content/themes/`
2. **Activate**: Kích hoạt theme trong WordPress Admin
3. **Customize**: Tùy chỉnh thông qua Appearance > Customize
